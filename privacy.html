This Privacy Policy explains what data [BOT NAME] (the "Service", operated by [YOUR NAME / ORGANIZATION]) collects through the Discord bot and its web dashboard, and how that data is used. The Service does not use the data it collects to train, fine-tune, or query any AI/ML model — all processing is rule-based.

1. Data We Collect

  • Discord identifiers. User IDs, usernames, guild IDs, and channel IDs as needed to execute commands, apply per-server configuration, and attribute moderation actions.
  • Message content — automated scanning only. Message text is scanned in memory by the auto-mod system. It is not stored unless a message is deleted by auto-mod or a moderator, in which case the message content is included in the mod-log embed posted to the server's designated log channel.
  • Moderation records. Warnings, kicks, bans, mutes, and auto-mod actions may be stored so server staff can review moderation history.
  • Server configuration. Module toggles, the configured mod-log channel, auto-mod keyword lists, and spam thresholds set by server administrators.
  • Saved playlists. Track lists a server chooses to save via the music module, associated with the guild and saving user's ID.
  • Dashboard authentication data. When you log in via Discord OAuth2, the dashboard may receive your Discord user ID, username, avatar, and server list to determine which servers you can manage.

2. Data We Do Not Collect

We do not collect message content outside the automated checks described above, do not read direct messages, and do not sell or share collected data with third parties for advertising or any other purpose.

3. Third-Party Services

Certain features may send limited data to third-party services necessary for that feature to function:

  • Discord — bot and dashboard functionality relies on the Discord API.
  • Lavalink (self-hosted) — search queries and track URLs for the music module may be sent to the audio node.
  • lyrics.ovh — artist and song title provided to a lyrics command may be sent to this public API.

4. Data Storage & Retention

Configuration, moderation records, and playlists may be stored in a database operated by the Service and retained according to the Service's data-retention practices.

6. Children's Privacy
